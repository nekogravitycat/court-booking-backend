# 2026-10-14 Frontend Changelog

## 新功能

### 使用者傳訊息給團主

- `POST /pickup-groups/{id}/host-messages`：任何登入使用者傳送站內通知給該團的團主。
  - body：`title`（1-100 字）、`content`（1-2000 字）。
  - 回傳 `201`（無 body）；團主傳給自己回傳 `400`；團不存在回傳 `404`；與 `POST /notifications` 共用每分鐘 10 次的限制（`429`）。
  - 團主收到的通知 `type` 為 `participant_message`，並帶有 `pickup_group_id`。

### 通知帶有寄件者

- `GET /notifications` 的每則通知新增 `sender_id`、`sender_name`（皆可為 `null`）。
  - 僅 `host_message`（團主 → 使用者）與 `participant_message`（使用者 → 團主）有值，其餘系統通知為 `null`。
  - 團主可用 `sender_id` 作為回覆對象。

## 行為變更

### 團主可回覆曾來訊的使用者

- `POST /pickup-groups/{id}/notifications` 的 `user_ids` 現在除了該團報名者，也接受曾對該團團主傳過訊息（`participant_message`）的使用者，讓團主能回覆尚未報名者的詢問。
- 省略 `user_ids` 的廣播仍只發送給該團報名者。
