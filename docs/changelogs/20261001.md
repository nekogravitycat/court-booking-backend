# 2026-10-01：帳號自評程度與一般使用者創團

## 帳號自評程度

- `GET /me/skill-levels`：以 `{items, page, page_size, total}` 單頁回傳所有已設定運動。
- `GET /me/skill-levels/{sport_id}`：讀取指定運動；尚未設定回傳 400。
- `PUT /me/skill-levels/{sport_id}`：body `{ "skill_level": 2 }`，建立或取代自己的設定。
- `DELETE /me/skill-levels/{sport_id}`：清除設定，冪等回傳 204。

每個帳號、每個運動各有一筆設定，可只設定自己有參與的運動。
程度須為該運動已定義且啟用的 1–100 整數，運動本身亦須啟用。
自評程度與 `/me/skill-ratings` 的主辦人評分獨立。

## 報名 API

`POST /pickup-groups/{id}/orders` 不需 body。伺服器讀取帳號中該團運動的設定，
保存為訂單的 `skill_level` 快照。舊客戶端傳入的 `skill_level` 會被忽略；
不能用報名 body 繞過帳號設定。尚未設定或運動/程度停用時回傳 400。

多人報名仍以 `members[0]` 表示本人，這筆 `skill_level` 可省略並由帳號設定覆蓋。
匿名同行者仍必須提供程度。所有成員程度均保存在訂單中。

選用快照的原因：修改帳號程度不應改變發起人先前審核的依據或既有程度統計。
取消後重新報名會重新取得當下的帳號程度。既有訂單保留原值；
不從舊訂單回填帳號設定，使用者須明確設定自己的程度。
快照保存程度整數，顯示標籤仍使用運動對照表。

## 創團權限

所有已登入且啟用的使用者都能建立臨打團，`host_id` 固定取自 Token。
創建者可編輯自己的團、審核報名及使用既有團主功能，無需 `is_pickup_host`。
不會自動授予 pickup host 角色；該角色仍用於既有教練清單與追蹤功能。
系統管理員仍能編輯任意團；刪除團的權限維持系統管理員限定。

新增 migration 000009，啟動時自動建立 `user_skill_levels`；不更動既有 migration。
