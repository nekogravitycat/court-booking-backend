# 2026-10-12 Frontend Changelog

## 新功能

### 團主傳訊息給報名者

- `POST /pickup-groups/{id}/notifications`：團主（或 System Admin）傳送站內通知給該團的報名者。
  - body：`title`（1-100 字）、`content`（1-2000 字）、選填 `user_ids`；省略 `user_ids` 表示發送給該團全部報名者。
  - 收件對象為該團任何狀態訂單的擁有者（不含團主本人與已停用帳號）。指定的 `user_ids` 必須都是該團報名者，否則 `400`。
  - 回傳 `201 {"sent": n}`；非團主回傳 `403`；與 `POST /notifications` 共用每分鐘 10 次的限制（`429`）。
  - 收件者的通知 `type` 為 `host_message`，並帶有 `pickup_group_id`。

## 行為變更

### 創團自動取得團主權限

- 成功創建臨打團（單團或批次）時，自動授予 Pickup Host 角色（`is_pickup_host = true`）。
- 角色不會因所有團結束而消失；既有已開過團的使用者已由 migration 回填。
